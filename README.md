# KNN Classification with sklearn

This project demonstrates the use of the **K-Nearest Neighbors (KNN)** algorithm from `scikit-learn` for classification tasks. It walks through data preparation, model training with varying `k` values, and evaluation using accuracy and confusion matrices.


## Steps involved are
- Used a standard classification dataset i.e. Iris dataset.
- Checked the information about dataset and check for missing values.
- Created a basic visualization of the data to see the distribution.
- Splitted the dataset into train and test set.
- Applied KNN classification model on trainig data set with neighbors varrying from 1 to 10 using a loop.
- Evaluated the model with every neighbor and made a graph of training and testing accuracy.
- Made a confusion matrix for all 3 species.
